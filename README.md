# PREDICTIVE MAINTENANCE
Purpose of this model is to guess Remaianing Useful Life (RUL). The reason we calculate this value is to teach the algorithm what engine sensor data looks like as it begins to degrade. 
### Dataset: NASA CMPASS Jet Engine Simulation
There are 4 subsets at the dataset: FD001, FD002, FD003, FD004. Each subset simulates a different condition.

**FD001:** 1 constant condition, only HPC fault.
**FD002:** 6 volatile condition
